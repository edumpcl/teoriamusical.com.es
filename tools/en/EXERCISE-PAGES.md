# Writing an English exercise page (/en/exercises/…)

Read first `tools/en/DICTIONARY-PAGES.md`: **everything in it applies** (module template, `dictionaryPage`, Spanish hrefs in links, language rules, facts, report) except what this file changes. A finished example: `tools/en/pages/ex-scales-identify-major-scales.js` (from `/ejercicios/escalas/escalas-mayores/`).

Each Spanish exercise page becomes **one file**: `tools/en/pages/ex-<section>-<slug>.js`, built with the same `dictionaryPage({...})`. Never edit shared files (`layout.js`, `build.js`, `links.js`, `dictionary-page.js`, anything in `assets/`), never run `build.js`/`version_assets.cjs`, never commit. Only write your page modules.

## Differences from dictionary pages
1. **Extract with the inline scripts**: `node tools/en/extract-es.js /ejercicios/<path>/ --keep-inline` (use `MSYS_NO_PATHCONV=1` or no leading slash in Git Bash). The widget container (`<div id="…">`) and its start-up `<script>` block must be copied **exactly** as in the Spanish body (ids, function names, config objects with Spanish strings: see rule 3). Put the engines the Spanish page loads in `scripts` (`extract-es.js` prints them: `tm-mei`, `tm-notacion`, `xxx-engine`, …; never `main`, `consent`).
2. **URL tree**: `/en/exercises/<section>/<slug>/`. Sections: `scales/` (escalas), `intervals/` (ejercicios-de-intervalos-musicales), `chords/` (acordes), `notes/` (identificar-notas, escribir-notas: `identify-notes/`, `write-notes/`), `rhythm/` (figuras, compases, grupos…), `ear-training/` (auditivos), `keys/` (tonalidades), plus single sections for tempo, dynamics, articulation, cadences, tonal functions, note equivalences (`tempo/`, `dynamics/`, `articulation/`, `cadences/`, `tonal-functions/`, `note-names/`). The exercises home `/en/exercises/` is a separate page written later; the **section hub** (the Spanish `index.html` of the section) is **yours**: write it as the section path itself (`/en/exercises/scales/`). Slugs: lowercase English words, short, how an English learner would search (`identify-major-scales`, `build-harmonic-minor-scale-with-key-signature`). Translate consistently inside your section (same word for same thing in all slugs).
3. **Widget configuration passed from the page**: some start-up calls pass Spanish strings (`titulo`, `subtitulo`, `grupos`…). The engine translates the known ones, so copy them unchanged; if a start-up call passes a string you cannot recognize as translated by the engine (check the engine's lookup map with grep), report it.
4. **Breadcrumb**: `crumbs: [['Music Exercises', '/ejercicios/'], ['<Section name>', '/ejercicios/<section>/']]` (omit the second for hubs, whose own label is the last crumb), Spanish hrefs.
5. **Printable PDF sheets**: the static PDFs under `/assets/img/**/fichas/` and previews are Spanish. **Leave out** the "Ficha para imprimir (PDF)" block (between `<!-- ficha-… -->` comments) and report it. Pages that have the on-page *sheet generator* (`#fichas`, engines `fichas-*`) keep it: those engines are translated.
6. **Sections of the body**: the interactive widget, the explanatory text under it (rewrite naturally for English readers; keep structure), the FAQ. Rewrite passages that only make sense for the Spanish music-education system (conservatorio grades, Spanish solfège as main names). Notes in letters; where the Spanish page uses solfège names in prose, use letters and say once "(C = Do in fixed-do countries)" only if the page teaches note names.
7. **Engines not translated yet** (do NOT write these pages; skip and report): the rhythm family (`figuras-engine`, `dictado-ritmico-engine`, `sincopa-engine`, `contratiempo-engine`, `grupos-valoracion-especial-engine`, `tipo-de-comienzo-engine`, `tipo-de-final-engine`) and the intervals / note-reading family (`intervalos-engine`, `fichas-intervalos-engine`, `lectura-notas-engine`) unless the lead tells you they are done.
8. Check the page really loads: after writing, `node -e "const p=require('./tools/en/pages/ex-….js'); console.log(p.path, p.title.length, p.description.length)"`; title ≤ 60, description ≤ 155. The lead runs the build and the browser tests.
9. Titles/descriptions: written for search ("Major Scales Quiz", "Build Triads", "Rhythm Dictation"), unique per page. Many pages of a section are variants (e.g. each inversion): make titles and intros distinct, keep the explanation short and precise rather than repeating whole paragraphs where the Spanish repeats them.

## Report (final message)
Per page: path and one line. Then **Errors found in the Spanish pages**, **start-up strings not covered by the engine**, **blocks left out** (PDF sheets, images with Spanish text, widgets without engine), **pages skipped (engine pending)**, **terms you were unsure about**.
