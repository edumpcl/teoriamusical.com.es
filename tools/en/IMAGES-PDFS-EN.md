# English versions of images and PDF sheets

**Convention (the build does the rest):** an English version of any `/assets/img/<path>` goes to `/assets/img/en/<path>` (same relative path and file name, so `assets/img/armaduras/orden-1-bemol.svg` -> `assets/img/en/armaduras/orden-1-bemol.svg`; PDFs, previews .png/.webp too). `node tools/en/build.js` rewrites, on English pages only, every reference to `/assets/img/<path>` into `/assets/img/en/<path>` when that file exists (it also refreshes the `?v=` hash). So page modules keep writing the Spanish path; you only produce the files and, where a block was left out of a page module, put the block back.

## Rules
- Spanish output must stay identical: add an option to the generator (e.g. `--lang=en`, or env `TM_LANG=en`) that changes labels and writes into `assets/img/en/...`; running without it must give the same files as before (verify with a hash or `git diff --stat` that Spanish assets did not change; do NOT regenerate Spanish assets otherwise).
- Language conventions: `tools/en/GLOSSARY.md`, `tools/en/ENGINE-I18N.md` (names: letters with ♯♭, intervals quality first `Major 3rd`, `Perfect 5th`, `whole step`/`half step`, `measure`, `time signature`, US names for notes values, scales `harmonic major`/`melodic major`, chords `dominant seventh`, `leading-tone (half-diminished) seventh`, figured bass `7, 6/5, 4/3, 4/2`). Engines for the in-browser sheet generators and the exercise pages are already translated: reuse their English strings so wording matches (grep `assets/js/*engine.js`, `tools/en/pages/ex-*.js`).
- Text drawn in SVG/PNG must stay readable (Arial #1a1a1a ≥16 px on images, see memory `feedback-etiquetas-imagenes`); notation always with VexFlow/Verovio as the generators already do, never hand-drawn.
- Page modules (`tools/en/pages/*.js`): the places that need the English asset are marked `TODO-IMG`, `NEEDS`, or are blocks of the Spanish page that were left out (e.g. the "Ficha para imprimir (PDF)" block between `<!-- ficha-… -->` comments; compare with `node tools/en/extract-es.js <esPath>`). Put the block back in English (translate headings, text, alt, figcaption, button labels; hrefs keep the Spanish asset paths: the build swaps them) and delete the TODO comment. Edit page modules ONLY with small `Edit` replacements (other agents edit other parts of the same files at the same time); never rewrite a whole module; never touch assets outside `assets/img/en/`, the generator you were assigned, and the module blocks that concern your assets.
- Do NOT run `tools/en/build.js`, `version_assets.cjs`, do not commit. Check each touched module loads: `node -e "require('./tools/en/pages/<file>.js')"`. View the produced PDFs/images (convert PDF pages to PNG with PyMuPDF/pdftoppm and look at them) before reporting; check there is no Spanish left (`pdftotext`, `grep` in SVG `<text>`).
- Shell: Git Bash; use `MSYS_NO_PATHCONV=1` when passing paths starting with `/`. Own scratch dir under the session scratchpad (a unique subfolder), because other agents share it. Servers: `node tools/serve.js <port>` with a port in your own range.
- Final report (Spanish, brief): files produced (counts), generator options added, page modules changed, anything left out and why, Spanish errors found, doubtful terms.
