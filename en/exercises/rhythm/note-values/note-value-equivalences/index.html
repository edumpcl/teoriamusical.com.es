Note Value Equivalences

The equivalences between note values tell you how many notes of one kind fit in another: two quarter notes (UK: crotchets) fit in a half note (UK: minim), and three eighth notes (UK: quavers) fit in a dotted quarter note. This exercise practices them in both directions, how many fit and which note equals a group, and also with dots and double dots.

Note value equivalence chart

Each note lasts twice as long as the next one. These equivalences do not depend on the time signature: a half note equals two quarter notes in 2/4 as well as in 6/8. What does change with the time signature is how many beats each note lasts, because in 2/4 the beat is the quarter note and in 6/8 it is the dotted quarter note.

With dots and double dots

A dot adds half of the value, so the note comes to last three of the notes that used to make two: a quarter note is two eighth notes, and a dotted quarter note is three. A double dot adds a second dot, which adds half of what the first one adds: a quarter note is four sixteenth notes, the first dot adds two and the second adds one. In total, 4 + 2 + 1 = seven sixteenth notes.

Frequently Asked Questions

How many eighth notes are in a dotted half note?
Six. The half note equals four eighth notes and the dot adds half of that, two more.
Which note equals three quarter notes?
The dotted half note: the half note equals two quarter notes and the dot adds one more.
Do note value equivalences change with the time signature?
No. A half note is always two quarter notes, whatever the time signature. What changes with the time signature is how many beats each note lasts.
