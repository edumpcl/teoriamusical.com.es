Add Up the Notes in a Measure

In this exercise you see several notes and rests in a row inside a measure (UK: bar), and you say how many beats they add up to. It is the step before completing measures: before you can tell which note is missing, you have to be able to add up what is already there.

How to add up the notes of a measure

  1. Look at the time signature. In 2/4, 3/4 and 4/4 each beat is a quarter note (UK: crotchet). In 6/8, 9/8 and 12/8 each beat groups three eighth notes (UK: quavers), so it equals a dotted quarter note.
  2. Work out how long each note and each rest lasts in that time signature. Rests count the same as notes.
  3. Add. In simple meters you get halves and quarters of a beat; in compound meters, thirds and sixths.
Simple metersCompound meters
Time signatures2/4, 3/4 and 4/46/8, 9/8 and 12/8
One beat isa quarter notea dotted quarter note (three eighth notes)
A quarter note lasts1 beat⅔ of a beat
An eighth note lasts½ a beat⅓ of a beat
A sixteenth note lasts¼ of a beat⅙ of a beat

For example, in 6/8: a quarter note (⅔) + an eighth note (⅓) + a dotted quarter note (1) = 2 beats, which is exactly one full measure. In 3/4: a dotted quarter note (1½ beats) + an eighth note (½) + a quarter rest (1) = 3 beats.

A trick for compound meters is to count in eighth notes: each beat is three. In the 6/8 example, the quarter note is 2 eighth notes, the eighth note is 1 and the dotted quarter note is 3: in total 6 eighth notes, which is two beats. To review the value of each note in each time signature, there is the exercise on note values.

Frequently Asked Questions

Do rests count when adding up a measure?
Yes. A rest lasts exactly the same as its note, so it is added up in the same way.
How do you add up notes in 6/8?
The easiest way is to count in eighth notes: each beat is three eighth notes. A quarter note is two eighth notes, a dotted quarter note is three and a dotted half note is six, which is a whole measure.
Why does a quarter note not last a whole beat in 6/8?
Because in 6/8 each beat groups three eighth notes. The quarter note lasts two eighth notes, so it lasts two thirds of a beat; the dotted quarter note lasts three eighth notes and lasts one whole beat.
