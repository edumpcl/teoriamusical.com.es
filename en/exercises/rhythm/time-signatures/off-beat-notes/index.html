Off-Beat Notes Exercises

This exercise teaches you to recognize an off-beat note without confusing it with a normal entrance, a syncopation or some other rhythmic rest. A rhythm excerpt appears in 2/4, 3/4 or 4/4, with quarter notes, eighth notes and rests. You have to tap on the staff the note that is off the beat (the one that is attacked on a weak beat or weak part of the beat, with a rest right before it and no tie), or press "No off-beat" if the excerpt has none.

TypeWhere the rest isWhere the note is attacked
Off-beat on a half beatThe strong part of a beatThe "and" (weak part) of the same beat
Off-beat on a whole beatA whole strong beatThe next, weaker beat

Off-beat quiz

How to use the exercise: choose between the normal mode (an excerpt of one measure, with no off-beat note or at most one) and the hard mode (excerpts of 2 measures, where there can be several off-beat notes at once, or none). Tap the note or notes that you think are off the beat, or "No off-beat" if the excerpt has none, and press Check. The app corrects right away and explains why it is or is not an off-beat note. Each test has 10 computer-generated questions with random notes, so the same excerpt almost never comes up twice.

What you practice: telling a real off-beat note from two classic distractors: a rest that comes before a note that does NOT fall on a weak part (it enters normally, so it is not off-beat) and a real syncopation (there is a tie, not a rest). Hint: look for the rest first; if right after it there is a note on a weak beat or weak part, it is off-beat. The rest does not need to be stronger than the note, only the note has to fall on a weak part.

Frequently Asked Questions

What is an off-beat note?
It is a note attacked on a weak beat or weak part of the beat with a rest right before it and no tie. The rest does not need to be stronger than the note: it is enough that the note falls on a weak part and a rest comes before it. If there is no rest, there cannot be an off-beat note.
How do I know if a note is off the beat?
Look for the rest first. For a note to be off the beat, it must enter on a weak beat or weak part right after a rest, and it must not be tied to any note. If there is no rest immediately before it, if the note does not fall on a weak part, or if the note is tied, it is not an off-beat note.
Which types of off-beat note appear?
Off-beat on a half beat (an eighth rest on the strong part of a beat, the note on the "and") and off-beat on a whole beat (a whole beat of silence, the note on the next weak beat). In both cases the note ends before the next strong part: if it sounded over it without being attacked again, it would be a syncopation, not an off-beat note.
Why are some excerpts with a rest not off-beat?
Because, although there is a rest, the note that enters after it does not fall on a weak part (it enters on a strong or medium-strong beat): it enters normally, not off the beat. The case of a real syncopation (a weak note tied to the strong one, with no rest) is also included.
What is the difference between an off-beat note and syncopation?
In an off-beat note there is an explicit rest right before the weak note. In syncopation there is no rest: the strong beat is absorbed by a tie, and the weak note is held over it. The off-beat note is sharper; the syncopation is smoother.
Are there printable worksheets?
Yes. You can generate as many different worksheets as you want directly in your browser, in a normal and a hard version, each with its own answer sheet, and print them freely for class.
How is the hard mode different from the normal one?
In the normal mode each excerpt has at most one off-beat note. In the hard mode the excerpt lasts 2 measures and can have several off-beat notes at once (or none): you have to tap every note that is off the beat.
