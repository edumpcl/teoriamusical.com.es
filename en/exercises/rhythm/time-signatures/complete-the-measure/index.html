Complete the Measure

These exercises to complete measures ask you to find what is missing: at the spot marked with a red line there is a gap, and you must say which note or rest goes there. It is the classic music-reading exercise, with three levels: one note is missing, one note or one rest is missing, or several notes are missing. Answers are checked right away, the feedback explains the count, and you can generate printable worksheets with solutions.

How to complete a measure

  1. Look at the time signature. In 2/4, 3/4 and 4/4 the beat unit is the quarter note (UK: crotchet); in 6/8, 9/8 and 12/8 it is the dotted quarter note, which equals three eighth notes (UK: quavers).
  2. Add up what is written, counting the rests too. What is missing is the difference up to a full measure (UK: bar).
  3. Check where the gap is. If it is in the middle of a beat, what is missing must complete that beat; if it starts on a beat, it can be a note value that fills a whole beat.

For example, in 3/4 with a quarter note, a gap and two eighth notes: what is written adds up to 2 beats, so 1 beat is missing, a quarter note. In 6/8 with a gap and three eighth notes: what is written adds up to 1 beat and another is missing, a dotted quarter note, or a quarter note and an eighth note if the gap allows two notes.

The measures are generated from real rhythms, grouped by beats: eighth notes are beamed by beat, and long note values start where they are actually written (a half note in 4/4 goes on beat 1 or beat 3). When several notes are missing, there can be more than one correct answer: any combination that exactly fills the missing duration is accepted, even if the score had it written another way. The feedback also shows how it was written.

Before this exercise

If you find it hard, first go through the value of note values in each measure and adding up the note values in a measure. To understand what a time signature says, there is the exercise on analyzing time signatures, and the theory is on the page about time signatures. Once this goes well, recognize the time signature tests what you learned the other way around: working out the time signature from the written rhythm.

And if you want to write rhythm by ear, with the same note cards, try the rhythmic dictation: you hear a rhythm of quarter notes and quarter rests and write it beat by beat.

Frequently Asked Questions

How do you know which note is missing in a measure?
Add up what is written, rests included, and subtract it from what fits in the measure. In 3/4 there is room for three quarter notes: if two are written, one quarter note is missing. In 6/8 the measure has two dotted-quarter-note beats (three eighth notes each): if a whole beat is missing, it can be filled with a dotted quarter note, with a quarter note and an eighth note, or with three eighth notes, depending on where the gap is.
Which time signatures are in the exercise?
The simple meters 2/4, 3/4 and 4/4, where the beat is the quarter note, and the compound meters 6/8, 9/8 and 12/8, where the beat is the dotted quarter note. You can practice each group separately or mixed.
Can a rest be missing?
Yes, at the second level. Rests last as long as the note of the same name, so they are counted the same way; the only difference is that you choose the rest instead of the note.
When several notes are missing, is any combination accepted?
Yes, as long as it exactly fills the missing duration. A one-beat gap in 6/8 can be filled with a dotted quarter note, with a quarter note and an eighth note, or with three eighth notes, and all three answers are accepted. The feedback also shows how it was written in the score.
