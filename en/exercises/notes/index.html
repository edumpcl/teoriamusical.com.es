Note Exercises: Read and Write Notes

Two interactive exercise sets to master the notes on the staff. In one you read a written note and name it. In the other you are given a name and write the note on the staff. Both work in the treble, bass, alto and tenor clefs, and in the rarer F and C clefs, and each quiz has 10 questions with instant answers.

Identify Notes on the Staff

A note appears on the staff and you choose its name. Pick the treble, bass, alto or tenor clef, one of the rarer clefs, or mix them all.

Read notes: identify notes on the staff

Write Notes on the Staff

You get a note name and click the staff to place that note in the clef you chose. It is the natural next step after reading.

Write notes: write notes on the staff

Which note names do the exercises use?

The exercises name the notes with letters: C, D, E, F, G, A and B. Countries that use fixed-do solfège call the same notes Do, Re, Mi, Fa, Sol, La and Si. If you want to practice translating between letters, solfège and the German system, try the note names quiz.

Not sure which clef is which? The musical clefs page in the dictionary shows each one and the instruments that read it.

Frequently Asked Questions

Should I read notes before I write them?
Yes, in most cases. Naming a note you see is easier than placing a note you only know by name, so start with the reading exercises and then move on to writing.
Which clefs are included?
The treble clef, the bass clef, the alto and tenor clefs, the F clef on the 3rd line, and the C clefs on the 1st and 2nd lines. There is also a mixed quiz for each exercise that uses all seven.
Do I need to register or install anything?
No. The exercises run in your browser and are free to use.
