4/4 Time Signature (Common Time)

4/4 time is a simple meter with four quarter-note (UK: crotchet) beats per measure (UK: bar). It is by far the most used meter in Western music, so much so that it is also called common time and written with the symbol C.

What does 4/4 mean?

In the time signature, the top 4 says the measure has four beats and the bottom 4 says the note value that gets one beat is the quarter note. Because it is a simple meter, each of the four beats divides into two equal parts (two eighth notes, UK: quavers).

How to count 4/4

Count "1 – 2 – 3 – 4", with the accent pattern Strong – Weak – Medium – Weak: the main accent falls on beat 1 and a secondary accent on beat 3. Each beat can be divided into two eighth notes, giving eight eighth notes per measure:

The C symbol: common time

4/4 is so common that it has its own symbol, inherited from old notation: the letter C, called common time. When that C is crossed by a vertical line (¢), it is no longer 4/4 but cut time (2/2, also called alla breve). You can see both symbols in context in the time signature analyzer.

Where is 4/4 used?

  • Pop, rock and electronic music: the vast majority of modern songs are in 4/4.
  • Classical music: found in every genre, from the symphony to the sonata.
  • Marches and band music: the quadruple pulse supports much of the repertoire.

4/4 compared with 2/4 and 12/8

Compared with 2/4, 4/4 has twice as many beats: it allows longer phrases and a secondary accent on beat 3. Compared with 12/8, its "compound twin," both have four beats with the same accent pattern, but 4/4 divides each beat in two and 12/8 divides it in three.

To practice this difference by ear, try the listening exercise recognize the meter by ear: count the beats from one accent to the next (4/4 versus 2/4) and notice whether each beat divides in two or in three (4/4 versus 12/8).

How to practice 4/4

Practice the four beats with the online metronome with 4/4 already selected: you will hear the accent on the first beat of each measure. To identify the time signature of a score, use the time signature analyzer.

Frequently Asked Questions

What is 4/4 time?
4/4 is a simple meter with four beats per measure, each worth a quarter note. It is the most used meter in Western music and is also called common time, written with the symbol C.
Is 4/4 simple or compound?
4/4 is a simple meter, because each beat divides into two equal parts (two eighth notes). Its compound twin is 12/8, which divides each beat into three.
What does the C in a time signature mean?
The C is the symbol for common time, which is the same as 4/4. When it is crossed by a vertical line (¢), it means cut time (alla breve), which is 2/2.
What is the difference between 4/4 and 2/4?
4/4 has four beats and 2/4 has only two. 4/4 allows longer phrases and has a secondary accent on beat 3, while 2/4 is lighter and more marked.
