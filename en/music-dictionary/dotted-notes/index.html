Dotted Notes and the Dot

The dot is a small point written to the right of a note (or a rest). It lengthens the note by half of its value. It is one of the most common tools of rhythmic notation.

What is a dot and how is it calculated?

The rule is simple: the dot adds half of the note's own value. A dotted note therefore lasts its original value plus half of that value, which is one and a half times its length.

For example, a quarter note (UK: crotchet) is worth 1 beat. Half of that is half a beat (an eighth note, UK: quaver). So a dotted quarter note is worth 1 + ½ = 1.5 beats, the same as a quarter note tied to an eighth note.

The value of each dotted note

Any note value can have a dot. Taking the quarter note as the beat, these are the durations of the seven dotted notes:

The dot on rests

The dot works in exactly the same way on rests: it lengthens the rest by half of its value. A dotted quarter rest is 1.5 beats of silence, just as a dotted quarter note is 1.5 beats of sound.

The double dot

The double dot is two dots in a row to the right of the note. The second dot adds half of the value of the first one, which is a quarter of the original note value. A double-dotted note therefore lasts its value plus a half plus a quarter (one and three quarters of its length).

For example, a double-dotted quarter note lasts 1 + ½ + ¼ = 1.75 beats, equal to a quarter note plus an eighth note plus a sixteenth note. The double dot is less common than the single dot, but it often appears in marches and in Baroque music.

The value of a dotted note depends on the time signature

The durations on this page take the quarter note as the beat, as in 2/4, 3/4 and 4/4. In compound meters (6/8, 9/8, 12/8) the beat is the dotted quarter note, so the counting changes: a dotted quarter note is worth 1.5 beats in 2/4 but 1 beat in 6/8. Practice: the dot is a tie

One thing does not depend on the time signature: every dotted note sounds exactly the same as a pair of tied notes (with a double dot, three tied notes). A dotted quarter note and a quarter note tied to an eighth note are the same sound written two ways. Test this equivalence in both directions with the interactive exercise.

Frequently Asked Questions

What is a dot in music?
A dot is a point written to the right of a note or a rest that lengthens it by half of its value. Any note value can have one.
How much does a dot add to a note?
The dot adds half of the note's value. A dotted note therefore lasts its original value plus half of it: one and a half times its length.
How long is a dotted quarter note?
A quarter note is worth 1 beat and half of that is half a beat (an eighth note), so a dotted quarter note lasts 1.5 beats, the same as a quarter note plus an eighth note.
What is a double dot?
A double dot is two dots in a row. The second dot adds half of the value of the first, which is a quarter of the original note value. A double-dotted note lasts its value plus a half plus a quarter. For example, a double-dotted quarter note lasts 1.75 beats.
Can a rest have a dot?
Yes. The dot works on rests just as on notes: it lengthens the rest by half of its value. A dotted quarter rest equals 1.5 beats of silence.
How much is a dot worth?
The dot is worth half of the note it follows. If the note lasts 2 beats, the dot adds 1; if it lasts 1, the dot adds ½. That is why a dotted note always lasts one and a half times its original value.
How long is a dotted half note?
A half note is worth 2 beats and half of that is 1 beat (a quarter note), so a dotted half note lasts 3 beats, the same as a half note plus a quarter note. It is the note that fills a measure of 3/4.
How long is a dotted eighth note?
An eighth note is worth ½ beat and half of that is ¼ beat (a sixteenth note), so a dotted eighth note lasts ¾ of a beat, the same as an eighth note plus a sixteenth note.
How long is a dotted whole note?
A whole note is worth 4 beats and half of that is 2 beats (a half note), so a dotted whole note lasts 6 beats, the same as a whole note plus a half note.
